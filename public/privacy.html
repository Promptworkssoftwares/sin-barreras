PRIVACIDAD

Política de Privacidad

Última actualización: 14 de septiembre de 2026

Quién opera Sin Barreras

Sin Barreras es un producto de Prompt Works. Para preguntas de privacidad puedes escribir a promptworks.dev@outlook.com.

Qué datos procesamos

  • Cuenta: nombre, email, identificadores de inicio de sesión, estado de verificación y preferencias.
  • Suscripción: proveedor, estado, identificadores de compra/suscripción y fechas. Sin Barreras no almacena números de tarjeta.
  • Contenido: texto que escribes, traducciones, historial sincronizado, frases guardadas, progreso, respuestas de aprendizaje y, cuando usas conversación QR, los turnos necesarios para entregar temporalmente la conversación a la otra persona.
  • Información sensible que tú decides aportar: el contenido libre puede incluir información de salud u otros datos sensibles (por ejemplo, al traducir síntomas en una situación médica). Solo se procesa para ejecutar la función que solicitas; evita incluir información que no sea necesaria.
  • Voz: el audio que decides grabar se envía cifrado al servidor y a proveedores de IA para transcribir, traducir o evaluar pronunciación. Sin Barreras no guarda el archivo de audio crudo en tu historial de cuenta.
  • Cámara: una imagen solo se procesa cuando eliges analizarla. La imagen cruda no se conserva en tu historial de cuenta.
  • Uso técnico: contadores de solicitudes, tokens, segundos de transcripción, costos estimados y datos técnicos de seguridad necesarios para operar y proteger el servicio. El alojamiento y la infraestructura pueden procesar datos de red como dirección IP y marcas de tiempo en registros técnicos.
  • Cache privado para reducir uso de IA: Sin Barreras puede conservar temporalmente, asociado a tu cuenta, resultados derivados como traducciones, audio TTS, lecciones preparadas y evaluaciones ya calculadas para evitar repetir llamadas de IA cuando vuelves a estudiar el mismo contenido. El cache expira automáticamente y se elimina cuando eliminas tu cuenta. El audio crudo de tu micrófono no se guarda en este cache.
  • Reportes de seguridad: si reportas una respuesta de IA, un mensaje QR o un participante, conservamos el motivo, el contenido reportado y datos mínimos relacionados para revisarlo.

Micrófono y cámara

Sin Barreras solicita estos permisos únicamente cuando activas una función que los necesita. La voz puede enviarse a servicios de IA para transcripción, traducción, TTS o práctica. Las imágenes pueden enviarse para lectura, traducción o explicación. Puedes negar el permiso y seguir usando las funciones que no lo requieren.

Para qué usamos los datos

  • Proporcionar traducción, aprendizaje, Coach, práctica, cámara, conversaciones QR y frases guardadas.
  • Autenticar tu cuenta, sincronizar progreso y gestionar acceso/suscripción.
  • Prevenir abuso, aplicar límites, resolver errores y estimar costos operativos.
  • Responder a reportes de contenido de IA y solicitudes de soporte.

Proveedores

Podemos utilizar proveedores que procesan datos únicamente para prestar el servicio, incluyendo OpenAI para funciones de IA, MongoDB Atlas para base de datos, Render para alojamiento, Stripe para pagos web, Google Play para compras Android, Google para OAuth y un proveedor SMTP para correos. OpenAI indica que los datos enviados mediante su API no se usan para entrenar sus modelos por defecto; sus propios términos y periodos de retención aplicables siguen rigiendo ese procesamiento.

Venta, publicidad y terceros

No vendemos tus datos personales. Sin Barreras no contiene publicidad de terceros. No utilizamos audio, imágenes ni traducciones para crear perfiles publicitarios.

Retención y eliminación

Conservamos la información de cuenta y el contenido sincronizado mientras mantengas la cuenta o hasta que lo elimines. Las salas QR temporales expiran automáticamente. Puedes eliminar permanentemente tu cuenta y los datos asociados desde la aplicación o desde la página pública de eliminación.

Al eliminar una cuenta, Sin Barreras elimina sus datos operativos de nuestros sistemas. Los procesadores de pagos pueden conservar registros mínimos de transacciones cuando sea necesario por obligaciones legales, contables, fiscales, prevención de fraude o disputas; esos registros no se utilizan para mantener una cuenta activa en Sin Barreras.

Seguridad

Utilizamos HTTPS, cookies de sesión seguras, contraseñas con hash, controles de acceso, límites de solicitudes y separación entre datos públicos y privados. Ningún sistema puede garantizar seguridad absoluta.

Edad

Sin Barreras está diseñado para adultos. No está dirigido a menores de 18 años.

Cambios

Podemos actualizar esta política cuando cambien las funciones o los proveedores. La fecha superior identifica la versión vigente.
